# Roteiro resumido do laboratório

| Etapa | Conceito | Ação principal |
|---|---|---|
| 00 | Refatoração segura | Entender o sistema e executar os testes |
| 01 | Clean Code + Regra do Escoteiro | Diagnosticar problemas sem alterar código |
| 02 | Nomes significativos | Renomear elementos ambíguos |
| 03 | Funções pequenas | Extrair responsabilidades do método principal |
| 04 | KISS | Simplificar regras condicionais |
| 05 | DRY | Eliminar duplicação de regras de negócio |
| 06 | YAGNI | Remover código especulativo e comentado |
| 07 | SoC | Separar formatação do recibo da regra de venda |
| 08 | Comentários + formatação | Melhorar comunicação do código |
| 09 | Tratamento de erros | Criar testes e mensagens contextualizadas |
| 10 | Coesão + acoplamento | Separar regras de desconto e frete |
| 11 | Object Calisthenics | Treinar restrições de design |
| 12 | Fechamento + Code Review | Comparar versões, revisar e justificar decisões |

Em todas as etapas, use o ciclo:

**LER → TESTAR → REFATORAR → TESTAR → REFLETIR → COMMITAR**
