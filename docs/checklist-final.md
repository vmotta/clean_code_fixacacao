# Checklist final do Laboratório de Clean Code

Esta lista não possui pontuação. Ela serve para conferir se você percorreu as principais experiências do laboratório.

- [ ] Executei a versão inicial antes de refatorar.
- [ ] Mantive testes como rede de segurança.
- [ ] Melhorei nomes que escondiam intenção.
- [ ] Extraí responsabilidades de métodos grandes.
- [ ] Apliquei KISS para reduzir complexidade desnecessária.
- [ ] Usei DRY em uma duplicação de conhecimento real.
- [ ] Usei YAGNI para remover código sem necessidade atual.
- [ ] Separei pelo menos uma responsabilidade relevante.
- [ ] Revisei comentários e formatação.
- [ ] Melhorei pelo menos uma situação de erro com teste explícito.
- [ ] Analisei coesão e acoplamento.
- [ ] Experimentei duas regras de Object Calisthenics.
- [ ] Mantive um histórico de commits pequenos e explicativos.
- [ ] Comparei o estado inicial e final.
- [ ] Recebi e respondi a Code Review.
- [ ] Consigo explicar três decisões de refatoração sem usar apenas “porque ficou mais bonito”.
