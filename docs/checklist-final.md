# Checklist de conclusão do laboratório

Este checklist não vale pontos. Ele serve para verificar se você percorreu o processo completo.

- [ ] Executei os testes antes de começar.
- [ ] Registrei um diagnóstico inicial do código.
- [ ] Melhorei nomes ambíguos.
- [ ] Dividi o método principal em responsabilidades menores.
- [ ] Apliquei KISS em uma regra complexa.
- [ ] Removi duplicação real aplicando DRY.
- [ ] Removi código especulativo aplicando YAGNI.
- [ ] Separei formatação de recibo da regra de venda.
- [ ] Melhorei comentários e formatação.
- [ ] Criei testes de caracterização para erros antes de mudar o tratamento.
- [ ] Melhorei mensagens/exceções de erro.
- [ ] Aumentei coesão e reduzi acoplamento em pelo menos uma parte.
- [ ] Pratiquei pelo menos três restrições de Object Calisthenics.
- [ ] Mantive os testes passando durante a evolução.
- [ ] Comparei a versão inicial com a final.
- [ ] Realizei ou recebi um Code Review técnico.
- [ ] Consigo explicar por que cada mudança melhora a manutenção.
