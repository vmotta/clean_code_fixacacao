# Exemplo de estrutura para o diagnóstico inicial

> Este arquivo mostra **como registrar** um diagnóstico, não as respostas do laboratório. Copie para `docs/meu-diagnostico.md` e preencha com suas próprias observações.

| Onde encontrei? | O que dificulta a manutenção? | Por que isso importa? | Conceito relacionado |
|---|---|---|---|
| Ex.: método/classe | Descreva com suas palavras | Explique o impacto para outra pessoa da equipe | Nome, KISS, DRY, SoC, etc. |

## Perguntas úteis

- Consigo entender a intenção sem reconstruir mentalmente cada linha?
- Se a regra mudar, quantos lugares precisarei alterar?
- Este método possui mais de uma responsabilidade?
- Há alguma decisão de negócio duplicada?
- Existe código mantido apenas porque “talvez precise um dia”?
