# Relação com o material de Clean Code

O laboratório foi organizado a partir dos temas do material fornecido para a disciplina. As explicações, analogias e exemplos deste repositório foram reescritos especificamente para a atividade em PHP.

Tópicos trabalhados:

- código limpo e código ruim;
- Regra do Escoteiro;
- KISS;
- DRY;
- YAGNI;
- Separation of Concerns;
- nomes significativos;
- funções e métodos;
- comentários;
- formatação e code style;
- tratamento de erros;
- coesão e acoplamento;
- Object Calisthenics.

O repositório não substitui a leitura do material-base. Ele funciona como prática orientada dos conceitos.
