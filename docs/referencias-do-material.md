# Referências ao material-base

Este laboratório foi organizado a partir do e-book **Clean Code – Codificação Limpa**, de Prof. Wagner Mendes Voltz.

## Correspondência entre laboratório e material

- Código limpo e legibilidade: capítulo “O código limpo”.
- Regra do Escoteiro: capítulo “Princípios para um código limpo”.
- KISS: tópico “Keep It Simple Stupid”.
- DRY: tópico “Don’t Repeat Yourself”.
- YAGNI: tópico “You Ain’t Gonna Need It”.
- Separation of Concerns: tópico “Separação de Responsabilidades”.
- Nomes significativos: capítulo “Como escrever um código limpo?”.
- Funções e métodos: mesmo capítulo.
- Comentários e formatação: mesmo capítulo.
- Tratamento de erros: mesmo capítulo.
- Coesão e acoplamento: mesmo capítulo.
- Object Calisthenics: capítulo “9 regras para que seu código fonte seja melhor!”.

As explicações deste laboratório são paráfrases didáticas. As analogias identificadas como **“Analogia do laboratório”** foram criadas especificamente para a turma e não são reproduções do e-book.
